Labeling rules
  • Label what the text says, not what you'd guess from the garment type or era.
  • If an attribute isn't mentioned, click none stated for that group. Saving with a group left empty is blocked, so a forgotten group can't pass as "none".
  • Words the list doesn't cover go in the other box (e.g. "lawn", "organza", "tulle"), separated by commas.
  • Materials include everything named, hardware too: "metal zipper" → metal, "glass buttons" → glass, "shell buttons" → other: shell. Lining and trim fabrics count. (Decided 2026-10-11.)
  • Hardware colors don't count: "black dome buttons" on a navy suit → navy only. Color describes the garment's fabric. (Decided 2026-10-11.)
  • A fiber named with a fabric gets both: "silk velvet" → silk + velvet; "silk jacquard" → silk (+ other: jacquard).
  • Exact list words only. Ivory is not cream; it goes in other. Fabric names that contain a list word count: "crepe de chine" and "satin crepe" → crepe; "velveteen" → velvet. Two-word colors take the more specific word: "navy blue" → navy, "rust brown" → rust. "Grey" → gray.
  • "Print" / "printed" → printing. "Pleated" → pleating. "Knit" → knitting. Pattern words (floral, plaid, striped) get no label.
  • Weaving only when the weave is a visible feature ("woven stripe", "woven pattern"). Plain "woven fabric/lining" gets no technique; "beads woven in" is beading. (Decided 2026-10-11.)
  • Technique is usually "none stated", so reread the text for these words before pressing Enter.
  • Skip only when the description is unusable (blank, not about the object, illegible).
